CookieHost

Why host a website normally when you can put it in cookies?

🥛 The oven is preheated.

Upload a tiny text-only website. Your browser packages it as JSON, gzip-compresses it, Base64URL-encodes it, splits it into ~3KB cookie chunks (cookiehost_0000…), and stores it right here in this browser. Nothing is uploaded to the server — the server is just a static shelf.

📄 html · css · js · json · txt · svg 🚫 no png / jpg / fonts / mp3 / pdf yet 📦 ~300–500KB max · cookies go on every request lol
